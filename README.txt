# Sukaina Birthday Surprise ❤️

This is a self-contained birthday website for Sukaina from Arif.

## Included
- Cinematic romantic opening
- Interactive balloon popping
- Personalized balloon messages
- Birthday cake + microphone blow interaction, with tap fallback
- Tamil + English personal letter
- Photo memory gallery using the supplied photos
- Final birthday message + confetti
- Soft synthesized background notes (starts after the first tap)

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and the `photos` folder.
3. In the repository, open Settings → Pages.
4. Select the main branch and root folder, then save.
5. GitHub will give you a public `github.io` link.
6. Open the link on your phone once to test it, then send it to Sukaina.

Microphone access generally requires HTTPS; GitHub Pages provides HTTPS. The tap fallback is included in case microphone access is denied.
